# cpp-name-initials

## About
My first beginner C++ project. It asks the user for their first, middle, and last name, then displays their full name and initials.

## Concepts Practiced
- Variables and `std::string`
- User input with `std::cin`
- Output with `std::cout`
- Accessing characters using `[0]`
- Basic program structure

## What I Learned
I practiced storing text, receiving user input, and extracting the first character of a string.
